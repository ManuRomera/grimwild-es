# Grimwild en castellano para FoundryVTT

Traducción no oficial al castellano del sistema Grimwild para FoundryVTT.

Este repositorio no es el sistema original ni reclama autoría sobre Grimwild, Moxie, el sistema FoundryVTT original, sus compendios originales, logos, texturas ni demás assets. Es una localización derivada preparada para uso personal en FoundryVTT.

## Proyecto original

- Sistema FoundryVTT original: https://github.com/asacolips-projects/grimwild
- Paquete en FoundryVTT: https://foundryvtt.com/packages/grimwild
- Grimwild y Oddity Press: https://www.odditypress.com/

## Qué incluye esta versión

- Traducción al castellano de cadenas i18n.
- Traducción de textos visibles en hojas, diálogos y controles del sistema.
- Traducción de compendios incluidos con el sistema.
- Reempaquetado de compendios LevelDB para FoundryVTT v13.

El identificador del sistema sigue siendo `grimwild` para conservar compatibilidad con las referencias internas de compendio (`Compendium.grimwild...`). Por ello debe usarse como sustitución del sistema oficial, no instalado en paralelo.

## Instalación

Este repositorio está pensado como copia traducida del sistema. Para instalación por manifest:

```text
https://raw.githubusercontent.com/ManuRomera/grimwild-es/main/system.json
```

Si el repositorio es privado, FoundryVTT no podrá descargar el manifest sin acceso autenticado. En ese caso instala la carpeta manualmente en:

```text
FoundryVTT/Data/systems/grimwild
```
